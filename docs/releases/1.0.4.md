# XSCS 1.0.4

运行程序只接受绝对路径 `--root ROOT`。安装、首次初始化、只读维护和离线密码重置由独立 XSSI 脚本及辅助程序实施；当前配置、DDL、凭据格式和资源声明从本仓库的权威定义构建导出。运行配置由管理员控制，服务账号只读，公共库固定到 XCSS 1.0.17。

发行包采用 SHA-256 校验。升级先下载并核验完整载荷，再控制启动、停止全部写入者、一致性备份、按目标当前契约只读检查、替换程序、启动并验收；失败恢复操作前匹配的完整环境。不转换旧结构，不覆盖配置、密钥或业务数据。

不识别访客 IP 或代理头。公共认证继续执行每个实际数据库每 60 秒最多 60 次登录尝试，成功不会清空计数，超额拒绝不会延长窗口；保留实例、文件及有界全局资源容量。运行检查使用 ROOT/run 的同代私有快照，避免重复复制数据库。

仅接受当前配置与数据契约，缺失或损坏明确失败，不自动重建。管理员凭据使用主数据库的公共管理表和 Argon2id 哈希。具体执行结果由对应提交、CI 和发行验收记录说明。
