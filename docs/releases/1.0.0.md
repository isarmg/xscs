# XSCS 1.0.0

服务端和管理 Web 的软件版本统一为 `1.0.0`。当前数据库身份使用 `xscs` / `v1`，结构修订为 `1`，自有 API、通信和持久数据格式统一为 v1；第三方软件及标准协议保留实际版本。旧数据身份和旧格式会在业务写入前被拒绝，不提供兼容或迁移。

服务端只负责运行，要求显式的绝对 `--root`。安装、目录与 systemd 创建、管理员初始化、SHA-256 校验以及事务升级由独立 XSSI/XSSC 脚本和辅助程序完成。配置由管理员控制，服务账号同组只读；安装、升级和服务启动分别执行完整的权限、数据库和业务验证。

管理台管理主机、实例和 Sunshine 管理操作。管理员账号、会话、登录限制和审计使用 XCSS 的唯一公共定义；公共 HTTP 诊断与产品日志写入 ROOT 的统一日志目录。管理页面采用统一圆角控件、UTC 时间和全部字体加载后启动的机制。

正式制品嵌入已验证的前端资源和当前安装材料，运行不依赖开发目录。发行包附带来源、组件清单和 SHA-256 校验文件；不使用自定义发行签名。

安装和运维见[操作指南](../operations.md)，当前命令见[CLI 参考](../cli.md)，构建与检查见[开发指南](../development.md)。
