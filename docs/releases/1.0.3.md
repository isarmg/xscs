# xscs 1.0.3

## 自 1.0.2 以来的更新

- 修复配置保存响应丢失后，先修改为其他值、再改回原值时复用旧任务回执的问题。每次新的配置编辑使用独立保存意图，避免界面确认已保存而客户端仍保留上一次配置。
- 保留未改动草稿的网络不确定重试身份；重新选择当前下拉项不会创建重复任务。配置编辑不会清除重启等其他操作的重试身份。
- 补充原组件回归测试，覆盖连续编辑、响应丢失、任务等待、重复重试与恢复默认。
- 软件与发行目录更新为 1.0.3。协议包、数据库 Schema、配置身份及依赖版本保持不变；不要求同步升级 xscc。

## 下载与安装

平台：Linux x86_64 GNU。发行资产：`xscs-1.0.3-x86_64-unknown-linux-gnu.tar.gz` 和 `xscs-1.0.3-x86_64-unknown-linux-gnu.tar.gz.sha256`。

安装步骤见[部署指南](../operations.md)。
