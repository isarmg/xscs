# xscs 1.0.2

## 自 1.0.1 以来的更新

- Sunshine 日志与虚拟输入状态查询分别展示等待、失败及结果状态。
- 刷新失败时保留上一份结果并提示重新读取，避免把历史结果误当成新请求成功。
- 补充查询失败、恢复与有效回执的回归测试。
- Rust 与内嵌管理 Web 同步升级至 xcss 1.0.5，包含共享日志轮转和管理界面修复。
- 软件与发行目录更新为 1.0.2；协议、数据库与配置身份保持不变。

## 下载与安装

平台：Linux x86_64 GNU。发行资产：`xscs-1.0.2-x86_64-unknown-linux-gnu.tar.gz` 和 `xscs-1.0.2-x86_64-unknown-linux-gnu.tar.gz.sha256`。

安装步骤见[部署指南](../operations.md)。
