# XSCS 2.0.0

服务端、`xscs-protocol`、Web 包和发行清单统一使用正式版号 `2.0.0`。运行目标为 Linux `x86_64-unknown-linux-gnu`，入口为 `xscs --root ROOT`。

## 主要变化

- 自定义 RustDesk 管理：管理员认证、实例绑定、凭据撤销、控制授权、地址上报、持久任务和审计；任务投递限于只读诊断。
- 管理界面采用 Rust/WASM xcss-web CSR，生产前端使用 Rust 构建链；Node/Playwright 用于浏览器验收。
- 移除旧 React/Vite 编译链及无生产用途的 `@xcss/web` npm 依赖，公共资源由带来源摘要的 vendor 快照提供。
- 补齐公共异步取消处理、资源来源校验和工具链回归检查。

## 数据格式与验收

数据格式保持 `v3`、schema revision `3`，DDL 和 schema 摘要不变，不自动转换旧状态。安装和正式发行继续使用现有 XSSI 契约。

真实设备串流、输入、重连、前后台切换、睡眠恢复和系统权限待独立验收，见 [原生集成与验收](../rustdesk-integration.md)。
