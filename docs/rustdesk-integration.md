# 等待 RustDesk 稳定后的接入

本轮只改变 xscs/xscc 的 `feat/management-prep` 分支，RustDesk 源码不变。本分支目前不应替换已部署服务。

先记录稳定 RustDesk 的完整 revision，并完成 Windows 主机与观看端构建、正常串流、音频、输入和重连验收，再按实际支持范围验证 Wayland/macOS。

之后统一工具链和依赖，给 RustDesk 添加 xscc 库依赖；由主机角色提供 NativeHost、NativeJournal、配对 UI 和受保护管理凭据，在已有 runtime 启动管理任务并参与退出流程。本库使用 Rust 1.99；接入时核对稳定 RustDesk 的工具链与锁定依赖，完成原生构建验证。

验证新建绑定、响应丢失恢复、凭据撤销、服务/桌面用户切换、断线执行与结果重放、保护存储失败、睡眠恢复和正常退出。替身诊断和网页测试不代替原生运行证明。

配置写入、短期会话票据、运行时权限撤销及媒体性能改造分别设计，在通过验收前不开放。正式升级前单独制定旧状态归档与显式迁移方案；不重新解释旧任务。
