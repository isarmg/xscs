# 通信与执行恢复

当前管理通道为 xscs-management/2，任务身份为 xscs-task/2。只读诊断是唯一可投递业务。

Server 使用 xcss 持久任务与审计，设备串行领取。任务从创建起最多等待 15 分钟，宿主诊断执行最多 10 秒。浏览器退出不取消已接受任务，重试使用原 Idempotency-Key。

xscc 在 RustDesk 的 runtime 中执行，断开 WSS 不取消已有执行；重连 Hello 声明进行中的任务。结果由宿主 Journal 先持久保存，Server 事务提交后才确认。丢失回执补交原结果，确认后保留去重身份及摘要。

设备凭据与安装身份、当前会话共同限制收存。旧会话、其他安装和不匹配摘要不能清理新结果。中断的只读任务失败并允许重新读取，unknown 与管理员核对结果分开保存。

宿主必须提供异步、原子、受保护且独占的 Journal。当前库不创建系统服务、runtime、进程或额外持久队列。原生权限、存储及睡眠恢复在 RustDesk 稳定后验收。
